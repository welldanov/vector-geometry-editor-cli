# Vector Geometry Editor CLI

Простой **векторный редактор с интерфейсом командной строки (CLI)**, реализованный на Python.  
Позволяет создавать и управлять геометрическими фигурами, выполнять вычисления и работать с ними через команды в терминале.

---

## Возможности

### Программа поддерживает работу со следующими фигурами:

- Point (точка)
- Segment (отрезок)
- Circle (круг)
- Square (квадрат)

### Доступные команды:
- `create <shape> <args>` — создание фигуры.
- `list` — вывод списка всех созданных фигур с их ID.
- `delete <id>` — удаление фигуры по идентификатору.
- `area <id>` — вычисление площади фигуры.
- `perimeter <id>` — вычисление периметра.
- `length <id>` — вычисление длины (для отрезков и окружностей).
- `distance <id1> <id2>` — расчет расстояния между центрами двух фигур.
- `translate <id> <dx> <dy>` — перемещение фигуры на плоскости.
- `compare <id1> <id2>` — сравнение площадей двух фигур.
- `help` — вывод справки.
- `exit` — завершение работы.

---

## Архитектура проекта

Проект разделен на несколько логических частей:

- handlers - обработчики CLI-команд
- shapes - классы геометрических фигур
- validators - валидация пользовательских команд
- utils - вспомогательные функции
- manager.py - основной менеджер фигур
- config.py - конфигурация (help текст)
- main.py - запуск CLI

---

## Основные компоненты

**ShapeManager**

Центральный класс приложения, отвечающий за:

- хранение фигур
- создание фигур
- удаление фигур
- вычисления (длина, площадь, расстояние и т.д.)

**Shapes**

Абстрактный базовый класс `Shape`, от которого наследуются:

- `Point`
- `Segment`
- `Circle`
- `Square`

Каждая фигура реализует только те операции, которые к ней применимы.

**Handlers**

Обработчики команд CLI:

- `create`
- `list`
- `delete`
- `length`
- `area`
- `perimeter`
- `distance`
- `translate`
- `compare`
- `help`

**Validators**

Отвечают за:

- проверку синтаксиса команд
- проверку типов аргументов
- корректность параметров фигур

## Установка и запуск

Требования:

- Python 3.10 или выше

Запуск программы:


```bash
python main.py
```

---

## Примеры использования

### Создание фигур

```bash
create point 1 2
create segment 0 0 5 5
create circle 3 3 10
create square 5 5 4
```

### Просмотр списка фигур

```bash
list
```

### Пример вывода:

```
1: Point(X=1.0, Y=2.0)
2: Segment(Point(X=0.0, Y=0.0) -> Point(X=5.0, Y=5.0))
3: Circle(CENTER=Point(X=3.0, Y=3.0), RADIUS=10.0)
```

### Вычисление параметров

```bash
length 2
area 3
perimeter 4
```

### Расстояние между фигурами

```bash
distance 1 3
```

### Перемещение фигуры

```bash
translate 3 10 5
```

### Сравнение фигур

```bash
compare 3 4
```

### Удаление фигуры

```bash
delete 2
```

### Справка

```bash
help
```

### Выход из программы

```bash
exit
```

## Обработка ошибок

### Программа проверяет:

- корректность команды
- количество аргументов
- тип аргументов
- существование фигур

### Пример ошибки:

```
error: Shape with id 10 doesn't exist
```
